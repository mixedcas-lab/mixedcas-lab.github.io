# 검증 기록

검증일: 2026-10-23. 로컬 Windows, Node.js 24.19.0, pnpm 11.25.0, Astro 7.4.2.

## 빌드와 파일 검사

- 정적 빌드 성공.
- 본문 8개 + 404 + 이전 주소 연결 6개, 총 15개 HTML 페이지 생성.
- `pnpm validate`: 내부 참조 282개, 앵커, 로컬 이미지, 중복 ID와 콘텐츠 필수 필드 검사 통과(공식 로고 반영 후 재검사).
- `node --check public/site.js`: 문법 검사 통과.
- 원본 칩 사진 1개, 교수 사진 1개, 학생 사진 9개, 갤러리 사진 83개 포함.
- 사용자 제공 공식 로고 PNG 2개 포함. 원본 파일과 SHA-256 일치.
- 사이트 내부 이미지와 스타일은 모두 로컬 파일이며 Google 임시 이미지 주소를 실행 중에 요청하지 않음.

## 브라우저에서 확인한 동작

- 데스크톱 첫 화면: 네이비/골드, 칩 이미지, 메뉴, 버튼 표시.
- 모바일 390px 프레임: 메뉴 열기와 Publications 이동, 메뉴 자동 닫힘.
- 모바일 논문 제목 검색 `GRID`: 해당 논문 1건.
- 데스크톱 연도 2026 + Conference 필터: ESSERC 항목 1건.
- 존재하지 않는 검색어: 0건 안내 표시.
- 갤러리: 38개 앨범/83장 데이터, 첫 앨범 열기, 1/2 → 2/2 이동, 사진 로드.
- 갤러리 닫기: 대화상자 닫힘, 원래 앨범 링크로 키보드 초점 복귀.
- 뉴스 검색 `과학기술정보통신부` + 2026: 1건. 새로고침 후 검색어·연도·결과 유지.
- `/mcas-preview/` 하위 경로로 실제 파일을 서비스한 상태에서 홈 메뉴와 자료 주소 확인.
- `/mcas-preview/member/professor/` 이전 주소가 새 People 페이지의 교수 위치로 연결.
- 320px 프레임에서 8개 본문 페이지 검사: 스크롤바를 제외한 표시 폭 305px와 문서 폭 305px로 일치. 가로 넘침 없음.
- 교수 프로필과 갤러리 확대 화면 시각 확인.

## 검증 범위

공식 로고 반영 후 추가 확인: 데스크톱 상단·하단의 흰색 로고, 밝은 배경 404 페이지의 네이비/하늘색 로고, 320px·390px·820px 프레임의 헤더 배치와 가로 넘침 없음, 320px 메뉴 열기. 하위 경로 `/mcas-preview/`에서 로고 표시를 확인했습니다. 검색·갤러리 등 변경하지 않은 기능은 위 기존 검사 결과를 유지합니다.

390px, 320px 확인은 브라우저의 같은 출처 iframe에 실제 페이지를 로드한 반응형 검사입니다. 실제 iOS/Android 기기 검사는 아닙니다.

외부 Scholar 검색 결과, 이메일 발송, 학교 DNS 전환은 실행하지 않았습니다. 실제 GitHub Actions 배포는 저장소에 올린 뒤 확인해야 합니다. 공개 주소를 모르는 정적 ZIP의 깊은 경로 404 제한은 DEPLOY 문서에 설명돼 있습니다.
