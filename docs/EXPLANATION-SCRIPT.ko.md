# MCAS 홈페이지 설명 대본

이 홈페이지는 서울시립대학교 MCAS 연구실의 기존 Google Sites 내용을, GitHub Pages에서 운영할 수 있도록 새로 구성한 사이트입니다.

디자인의 중심은 네이비와 실제 칩 사진입니다. 첫 화면에는 연구실에서 공개했던 칩 사진을 크게 배치했고, 골드 색상과 여백을 이용해 연구실의 정체성이 드러나도록 했습니다. 연구 소개와 논문 목록은 밝은 배경을 사용해 읽기 편하게 만들었습니다.

상단과 하단에는 연구실에서 제공한 공식 MCAS 로고를 넣었습니다. 네이비 배경에는 흰색 버전을, 밝은 배경에는 네이비와 하늘색 버전을 사용합니다. 로고의 모양과 색을 그대로 유지하고, 휴대폰에서는 화면 폭에 맞춰 크기만 조정합니다.

메인 화면은 연구실 소개, 연구 분야, 대표 논문, ADC Census, 연구실 생활, 최근 소식, 대학원생 모집 순서입니다. 전체 논문과 뉴스는 별도 페이지에 있어 메인 화면이 긴 게시판처럼 보이지 않습니다.

기존 홈페이지에서 연구 분야 5개, 교수 소개, 학생 페이지에 있던 구성원 9명, 논문과 원고 30건, 특허 8건, 소식 40건, 강의 기간 8개, 사진 앨범 38개를 옮겼습니다. 사진 앨범에는 83장이 들어 있습니다. 기존에 '심사 중'이었던 원고는 그대로 표시했고, 확인되지 않은 DOI를 임의로 붙이지 않았습니다.

관리 방식은 세 부분입니다. GitHub는 파일과 변경 기록을 보관합니다. Astro는 그 파일로 웹페이지를 만듭니다. GitHub Pages는 완성된 웹페이지를 공개합니다. 변경 사항이 GitHub의 main 브랜치에 들어가면 자동 검사와 배포가 실행되도록 설정 파일이 포함돼 있습니다.

평소에는 홈페이지 코드를 직접 만질 필요를 줄였습니다. 논문, 구성원, 뉴스, 갤러리 등의 내용은 src/data 폴더의 파일에 따로 보관합니다. 예를 들어 '이 논문을 추가해줘'라고 AI에게 요청하면 publications.json을 수정하고, '이 학생 사진을 바꿔줘'라고 하면 members.json과 이미지 파일을 수정하면 됩니다. 페이지 배치를 바꾸는 작업과 글을 추가하는 작업을 분리한 구조입니다.

다른 AI가 이 작업을 이어받을 때는 저장소 전체와 AI-HANDOFF.md를 전달하면 됩니다. 이 문서에는 목적, 디자인 기준, 데이터 구조, 실행 방법, 검사 방법, GitHub 배포 절차가 들어 있습니다. AI는 기존 구조를 유지하면서 요청한 부분만 수정할 수 있습니다.

지금 전달된 것은 실제 동작하는 홈페이지 파일과 배포 준비물입니다. 현재 운영 중인 Google Sites와 GitHub에는 아직 변경을 가하지 않았습니다. 새 GitHub 저장소에 올려 화면을 확인한 다음, 원하면 학교 측 도메인 설정을 바꿔 기존 mcas.uos.ac.kr 주소로 연결할 수 있습니다.

한 가지 확인할 내용은 기존 페이지 사이의 정보 차이입니다. 일부 학생은 학생 목록에 남아 있지만 소식에는 졸업 기록이 있고, 연락처 페이지와 교수 소개의 전화번호도 다릅니다. 이런 부분은 자동으로 추측해 바꾸지 않았으며 별도 확인 문서에 정리했습니다. 연구실에서 맞는 내용을 알려주면 데이터 파일만 수정해 반영할 수 있습니다.
